# EXTRACTION OPÉRATIONNELLE — VERSION DÉFINITIVE (document charnière)

> **Statut : CONSOLIDATION OPÉRATIONNELLE — version définitive, verrouillée avant toute architecture.**
> Document **charnière** entre le **modèle consolidé v2**, la fondation **`CONSCIENCE_DU_PROJET`** et la
> future architecture. **Objectif unique** : vérifier que le basculement **production → pilotage** est
> **entièrement traduit** dans le fonctionnement du système. **Ce n'est pas** un document conceptuel/
> philosophique, **ni** une conception de cockpit. **Aucune implémentation · aucune architecture · aucun
> écran · live intact · fichiers verrouillés intacts · zéro dépense.**
>
> **Sources exclusives** : `docs/CONSCIENCE_DU_PROJET` (fondation) + modèle consolidé v2 (24 objets,
> taxonomie 4 niveaux, 15 invariants). **Aucun nouvel objet.**
>
> **Acquis validés — tous intégrés (vérifié, aucun manquant)** : cap = centre de gravité · média =
> manifestation temporaire · état naturel = **repos** (cap+situation+mémoire) · matière **convoquée puis
> redescendue** · **signale sans décider** · **décrit sans attribuer le sens** · tensions **stratifiées** ·
> tensions constitutives **déclarées OU émergentes** · **protection contre l'aplatissement** · **cap agi**
> révélant une intention en maturation · **lisibilité complète sans média** · **compression** =
> cap+situation+tension principale+prochain geste · **distinction stricte production / pilotage /
> conscience / matière / livrable**.
>
> Convention de chapitre : **(a) CONSERVÉ · (b) CHANGE · (c) CONSÉQUENCES** sur les **8 dimensions** —
> *objets · états · relations · calculs · comportements · décisions · mémoire · cohérence*.

## CHAPITRE 1 — OBJETS
**(a) Conservé** : les **24 objets** de v2, leurs identités, l'**Univers** (objet de 1er niveau), le
**Livrable** distinct, la taxonomie 4 niveaux.
**(b) Change** : la **primauté** se déplace vers le **cap** (Intention composite + identité-essence +
origine/déclencheur) ; la **matière** (Média produit) devient une **manifestation secondaire** ; la
**conscience** (noyau) devient une **lecture de 1er plan dérivée** ; « média actif » reste un **rôle**, pas
un objet-trône.

| Dimension | Conséquence |
|---|---|
| Objets | aucun ajout/retrait ; **réordonnancement de primauté** (cap > matière) |
| États | le **projet** gagne une **posture** (repos/travail) au-dessus des états média |
| Relations | le **cap** devient la **racine de lecture** ; la matière y est rattachée, secondaire |
| Calculs | la **conscience/situation** devient une **dérivation calculée** du noyau |
| Comportements | on « tient » un **cap**, pas un média |
| Décisions | portent **d'abord** sur le cap, **ensuite** sur la matière |
| Mémoire | le **noyau** (cap+identité+décisions+config) = ce qui persiste **sans média** |
| Cohérence | l'**étalon** de cohérence = **le cap**, pas la qualité technique du média |

---

## CHAPITRE 2 — ÉTATS
**(a) Conservé** : les états du Média produit (candidate/variante/écartée/retenue), du Livrable
(en construction/validé/prêt-à-poster/archivé), du QC, de la Décision, du Projet (brouillon/en cours/
finalisé/archivé).
**(b) Change** : ajout d'une **posture calculée** **repos (défaut) / travail (excursion)** ; les états média
**vivent “en dessous”** (ne déterminent plus *où en est* le projet) ; ajout de **signaux de conscience**
déterministes **calme / maturité / tension / priorité**.

| Dimension | Conséquence |
|---|---|
| Objets | « média actif » = **rôle** (niveau 4), jamais un état dominant |
| États | nouvel **axe posture** (repos/travail) + **signaux dérivés** au niveau projet |
| Relations | la posture **dérive du noyau**, **pas** d'une étape de pipeline |
| Calculs | **calme/maturité/tension/priorité** = calculs déterministes (mêmes faits → même état) |
| Comportements | l'état **par défaut** est le **repos** |
| Décisions | une décision **fait sortir** du repos (travail) puis **y ramène** |
| Mémoire | un état média **convoqué** devient un **fait** mémorisé après verdict |
| Cohérence | « tension/priorité » **provient** du miroir stratifié (ch. 4) |

---

## CHAPITRE 3 — COMPORTEMENTS
**(a) Conservé** : réversibilité ; impact aval **garder/mettre à jour/régénérer** ; **confirmation de coût
avant dépense** ; gates (QC avant production coûteuse).
**(b) Change** : comportement **par défaut = présenter le repos** (cap+situation+tension+geste), **sans
convoquer de matière** ; **convocation à la demande** ; **signale, ne décide jamais** (Loi I) ; **retour au
repos enrichi** après chaque excursion.

| Dimension | Conséquence |
|---|---|
| Objets | la matière n'est **jamais le substrat** ; elle est convoquée |
| États | toute action **commence en repos** et **y revient** |
| Relations | production/pilotage **séparés** : produire est une **excursion**, pas l'épine dorsale |
| Calculs | le **prochain geste** est **proposé** (calculé), jamais exécuté d'office |
| Comportements | **aucune** promotion/correction automatique (Loi I) |
| Décisions | l'**impact aval** reste un **choix explicite** (jamais en silence) |
| Mémoire | chaque excursion **dépose** décisions + faits avant de redescendre |
| Cohérence | le **miroir** accompagne en continu, sans bloquer ni trancher |

---

## CHAPITRE 4 — COHÉRENCE
**(a) Conservé** : la cohérence **signale sans décider** (INV-2) ; un **écart assumé = une décision** ; les
**10 pièces** surveillées ; pas de jugement de goût.
**(b) Change** : **stratification lexicographique** (cap-âme[identité>émotion/message] > cap-cadre >
manifestations > production) ; **fracture vs polarité constitutive** (strate ⓪) ; **inversion de
signalement** (une polarité **protégée** → on signale son **effondrement**) ; **protection contre
l'aplatissement** ; prise en compte du **cap agi** (intention en maturation).

| Dimension | Conséquence |
|---|---|
| Objets | la **polarité protégée** = **marqueur (niveau 3)** attaché au cap *(à reformuler, cf. §non-contradiction)* |
| États | par pièce : aligné/à vérifier/non défini/**écart assumé** ; +**effondrement** d'une polarité |
| Relations | une tension de **cap invalide l'aval** dépendant (dépendance/gaspillage) |
| Calculs | classement **strate puis gravité** ; détection fracture/polarité ; écart **déclaré vs agi** |
| Comportements | surface **d'abord** la strate la plus haute ; **propose** un carrefour |
| Décisions | corriger **ou** assumer ; **revendiquer** une polarité = décision qui **inverse** le signal |
| Mémoire | écarts assumés et polarités protégées **persistent** comme décisions/marqueurs |
| Cohérence | deux devoirs : **anti-incohérence** ET **anti-simplification prématurée** |

---

## CHAPITRE 5 — ÉTAT DE REPOS
**(a) Conservé** : rien (le repos **n'existait pas**) — mais il **s'appuie** sur des invariants existants :
dossier = source de vérité (INV-10), survie de l'état (INV-9).
**(b) Change** : le **repos** devient l'**état calculé de 1er plan** = **cap + situation + mémoire** ;
**compression en « titre »** via les **4 filtres déterministes** (pertinence au cap · rôle/statut ·
structurant vs local · pertinence à l'écart présent) ; **signaux** calme/maturité/tension/priorité.

| Dimension | Conséquence |
|---|---|
| Objets | la **situation** = **vue dérivée**, jamais un objet/source nouveau |
| États | **repos** = posture par défaut ; signaux calculés |
| Relations | le repos **dérive** du noyau (cap, identité, décisions, config) |
| Calculs | **titre** déterministe (4 filtres) ; signaux reproductibles |
| Comportements | au repos, **aucune matière convoquée** |
| Décisions | le repos **expose** la tension principale + un **prochain geste proposé** |
| Mémoire | la mémoire **nourrit** la situation (le pourquoi reste lisible) |
| Cohérence | le **signal de priorité** = la tension de plus haute strate (carrefour) |

---

## CHAPITRE 6 — RELATION À LA MATIÈRE
**(a) Conservé** : le **Média produit** et ses états ; le **RAW** jamais écrasé ; le **Livrable** comme
paquet ; la production réelle (gatée).
**(b) Change** : **cycle de convocation** — la matière **monte au premier plan pour un motif**, **avec son
verdict attaché** (état décidé + raison), puis **redescend comme fait** ; **asymétrie de permanence**
(cap/situation/mémoire permanents, matière transitoire) ; **taille ≠ primauté**.

| Dimension | Conséquence |
|---|---|
| Objets | Média produit = **manifestation** ; jamais le substrat |
| États | la matière n'a un premier plan **que pendant** sa convocation |
| Relations | matière **rattachée** au projet, **subordonnée** au cap |
| Calculs | le volume de matière **n'augmente pas** la primauté (≠ pondération) |
| Comportements | produire/comparer = **excursion** bornée, retour au repos |
| Décisions | le **verdict** (retenue/écartée…) est **attaché** au moment de la convocation |
| Mémoire | après verdict, la matière **redescend en fait** durable |
| Cohérence | la matière est **jugée par rapport au cap**, pas pour elle-même |

## CHAPITRE 7 — VISIBLE OU CALCULÉ (opérationnel, sans écran)
**(a) Conservé** : **tout dérive du dossier-projet** (source de vérité, INV-10) ; rien ne « détient » l'état
en dehors.
**(b) Change** : sont désormais **calculés et disponibles sans aucun média** — le **titre**
(cap·situation·tension·geste) ; la **situation** (vue dérivée) ; la **focalisation** (classement calculé →
carrefour) ; l'**inventaire-faits** (décisions+raisons, variantes, versions, livrables — **faits**, pas
galerie) ; les **marqueurs réservés** (vocabulaire **fermé/déterministe** : signaux + polarité protégée/
effondrement).

| Dimension | Conséquence |
|---|---|
| Objets | aucun nouvel objet ; ce sont des **dérivations** (niveau 4) |
| États | les signaux d'état sont **exposés** comme lecture primaire |
| Relations | les vues (titre/situation/inventaire) **dérivent** du dossier |
| Calculs | **lisibilité complète sans média** = exigence de calcul (titre toujours productible) |
| Comportements | la lecture primaire **n'exige jamais** de convoquer un média |
| Décisions | le **prochain geste** est exposé comme **proposition** |
| Mémoire | l'inventaire-faits **expose** la mémoire à la demande |
| Cohérence | les **marqueurs réservés** portent un **sens fixe** (jamais du texte libre interprétatif — Loi II) |

## CHAPITRE 8 — ANTI-PATTERNS
**(a) Conservé** : la vigilance « une fonction = une place » (E105) et « l'UI ne détient jamais l'état »
(E122/INV-10) restent valides et **renforcées**.
**(b) Change** : **interdiction explicite** de toute retombée **média-centrée** (liste exhaustive ci-dessous).

| Dimension | Conséquence |
|---|---|
| Objets | interdit de faire d'un média le **substrat** du projet |
| États | interdit que « l'étape de pipeline » **soit** l'état du projet |
| Relations | interdit que la matière **domine** le cap dans la lecture |
| Calculs | interdit qu'une lecture **exige** un média pour se produire |
| Comportements | interdit d'**ouvrir sur la production** par défaut |
| Décisions | interdit toute **promotion/correction automatique** (Loi I) |
| Mémoire | interdit d'exposer la mémoire comme **galerie** (au lieu de faits) |
| Cohérence | interdit de réduire la cohérence à un **contrôle technique** du média |

## TABLEAU DE CONSOLIDATION FINAL (A → B → C)

| A — héritage production/média | B — correction cap/conscience | C — conséquence fonctionnelle concrète |
|---|---|---|
| Le projet ≈ son média | Le projet = son **cap** (intention+identité+origine) | le « handle » = **cap+situation**, pas `média actif` |
| Ouvrir/rouvrir sur la production | État **par défaut = repos** | au démarrage/à la reprise : **titre** (cap·situation·tension·geste), **0 média convoqué** |
| Aperçu média permanent au premier plan | Matière **convoquée puis redescendue** | la matière monte **pour un motif**, **avec verdict**, puis devient **fait** |
| Pipeline = colonne vertébrale | Pipeline = **excursion** de pilotage | produire ne définit plus l'état ; on **revient au repos enrichi** |
| « média actif » = centre | « média actif » = **rôle exclusif** (niveau 4) | un seul, réassignable, **jamais un trône** |
| Cohérence = contrôle technique plat | Cohérence = **miroir stratifié** | classement **strate puis gravité** ; cap invalide l'aval |
| Tensions non hiérarchisées | **Stratification lexicographique** | aucune accumulation de tensions de production ne dépasse une tension de cap |
| Contradiction = à résoudre | **Fracture vs polarité** + **inversion** | une polarité **revendiquée** est **protégée** ; on signale son **effondrement** |
| Intention = donnée figée / légende | **Cap vivant** (déclaré **et** agi) | signal **maturité** quand le cap agi révèle une intention en maturation |
| Mémoire = journal d'actions | Mémoire = **le pourquoi** (décisions+raisons) | projet **relisible** ; situation **dérivée** de la mémoire |
| Outil qui « fait » | Outil qui **signale/décrit** (Lois I & II) | **aucune** décision ni **attribution de sens** par le système |
| Lisible **avec** média | **Lisible sans aucun média** | le **titre** est toujours productible, médias absents |

## ANTI-PATTERNS INTERDITS (liste exhaustive)
1. **Placeholder** — une matière de remplissage « pour qu'il y ait toujours un média ».
2. **Substrat bloc-média** — le projet **construit comme** un média auquel on accroche le reste.
3. **Aperçu permanent dominant** — un média en tête, **en continu**, comme cœur du projet.
4. **Galerie au repos** — un étalage de médias par défaut au lieu de cap+situation.
5. **Pipeline de production comme colonne vertébrale** — la séquence source→paramètres→finaliser comme
   structure portante.
6. **Média actif comme centre permanent** — la source courante traitée en centre plutôt qu'en **rôle**.
7. **Cap réduit à une légende** — l'intention reléguée à une ligne décorative au-dessus d'un média.
8. **Production ouverte par défaut** — démarrer/rouvrir sur l'acte de fabriquer.
9. **Coût/QC comme centre** — un contrôle technique érigé en sujet du projet.
10. **Galerie de variantes permanente** — variantes exposées en continu au lieu d'être **convoquées**.
11. **Situation/titre stockés comme source** — au lieu d'être **dérivés** du dossier (viole INV-10).
12. **Signal interprétatif** — un marqueur qui **attribue un sens** au lieu de décrire un fait (viole Loi II).
13. **Geste imposé** — un « prochain geste » **exécuté** au lieu de **proposé** (viole Loi I).
14. **Toute autre forme** qui **redonne la primauté au média** sur le cap.

## VÉRIFICATION DE NON-CONTRADICTION (rien n'est masqué)
> Statuts : **✅ compatible** · **♻️ à reformuler** (compatible, mais terminologie/rattachement à préciser
> avant architecture) · **⛔ CONTRADICTION** (bloquant).

### vs les 24 OBJETS
- **✅ compatible.** Aucun objet ajouté/retiré ; le paradigme **réordonne la primauté** (cap > matière) sans
  contredire un objet. **♻️ à reformuler** : la **présentation** de « média actif » (rôle, jamais trône) et
  du Média produit (manifestation) — c'est une reformulation de **primauté**, pas une atteinte à l'objet.

### vs les CYCLES DE VIE
- **✅ compatible.** Les cycles (naître/évoluer/valider/archiver/réutiliser) sont **inchangés**. **♻️ à
  reformuler** : l'état « par défaut » d'un projet est désormais lu comme **repos** (au-dessus des états de
  cycle) — couche opérationnelle ajoutée, **sans** modifier les cycles.

### vs les DÉCISIONS
- **✅ compatible** (et renforcé). Le pilotage **EST** un enchaînement de décisions ; la **stratification**
  ne fait qu'**ordonner** leur traitement. M16/M17 (1 action=1 décision ; sans raison=incomplète) **tiennent**.

### vs la MÉMOIRE
- **✅ compatible** (et renforcé). La conscience **s'appuie** sur la mémoire (décisions+raisons, versions) ;
  rien n'est effacé (INV-5/8). La **situation** est une **dérivation** de la mémoire, pas un stock nouveau.

### vs les 15 INVARIANTS (un par un)
- INV-1 primauté intention → **✅ renforcé** (le cap devient le centre).
- INV-2 signale sans décider → **✅ renforcé** (Lois I & II explicitées).
- INV-3 objet/état/action/décision → **✅ renforcé** (média actif = rôle ; matière = manifestation).
- INV-4 décision = pourquoi → **✅ compatible**.
- INV-5 immuabilité du passé → **✅ compatible**.
- INV-6 réversibilité jusqu'à publier → **✅ compatible** (travail = excursion réversible).
- INV-7 un seul acte irréversible → **✅ compatible**.
- INV-8 rien ne se perd en silence → **✅ compatible**.
- INV-9 survie de l'état complet → **✅ compatible** *(condition : situation/titre **dérivés** et
  **recalculables** depuis le dossier — jamais stockés comme source ; cf. anti-pattern 11)*.
- INV-10 source de vérité unique → **✅ renforcé** (situation/titre/inventaire = **vues dérivées**).
- INV-11 étanchéité par copie → **✅ compatible**.
- INV-12 contrat d'effet → **✅ compatible** (effets annoncés ; geste proposé).
- INV-13 capitalisation tracée → **✅ compatible**.
- INV-14 hiérarchie du monde → **✅ compatible** (l'Univers = l'**appartenance** du noyau).
- INV-15 indépendance du médium → **✅ renforcé** (lisibilité complète sans média).

### vs l'UNIVERS (objet de 1er niveau)
- **✅ compatible** (et renforcé). L'Univers est l'**appartenance** dans le noyau de conscience ; le
  **cap-cadre** s'appuie sur ses règles/objectif (copiés, M12). Aucune contradiction.

### ♻️ POINTS À REFORMULER AVANT ARCHITECTURE (non bloquants, mais à clarifier)
1. **Terminologie « identité »** : l'**identité-essence** (composante du cap-âme) ≠ l'**identifiant stable**
   du projet (M18) ≠ l'**identité du Personnage**. Trois sens à **nommer distinctement**.
2. **Intention composite vs strates** : les composantes de l'Intention (message/émotion/public/objectif)
   sont **réparties** entre cap-âme (émotion/message) et cap-cadre (public/objectif) **pour le classement
   des tensions** — l'**objet Intention reste un** ; c'est une **lecture stratifiée** de ses parts, à
   formuler clairement.
3. **Polarité protégée** : où la **rattacher** ? Défaut proposé — **marqueur de niveau 3 attaché à
   l'Intention/au cap** (comme le déclencheur), **sans nouvel objet** (cohérent M24). *À confirmer.*
4. **Signaux & marqueurs réservés** : fixer le **vocabulaire fermé** (calme/maturité/tension/priorité +
   polarité/effondrement) comme **dérivations niveau 4**, déterministes.

### RÉSULTAT GLOBAL
> **Aucune CONTRADICTION bloquante.** Le paradigme cap/conscience est **compatible** avec l'intégralité du
> modèle v2 et des 15 invariants — qu'il **renforce** en plusieurs points (INV-1/2/3/10/15). Restent **4
> reformulations** (terminologie/rattachement, ci-dessus) à clarifier **avant** d'architecturer — **aucune**
> ne remet en cause le modèle ; ce sont des **précisions de nommage et de niveau**.
