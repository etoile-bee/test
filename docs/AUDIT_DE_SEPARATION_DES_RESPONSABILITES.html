FICHES D'ÉTANCHÉITÉ (par espace)

① SOCLE (dossier-projet)

  • Responsabilités exclusives : détenir et conserver la vérité durable d'un projet.
  • Responsabilités interdites : calculer une lecture · décider · convoquer la matière ·

interpréter.

  • Données possédées exclusivement : noyau (cap, identité-essence, origine/déclencheur, appartenance),

identifiant stable (M18), mémoire (Décisions+raisons, journal de versions), configuration (instances

appliquées, verrous, marqueurs de polarité protégée niv.3), matière (Média produit + états, RAW),

Versions, Livrables, statuts.

  • Calculs autorisés : aucun.
  • Calculs interdits : tous (situation, titre, signaux, tensions, miroir, qualification…).
  • Écritures autorisées : être écrit par le Pilotage (décisions/états) et l'Atelier (faits-médias).
  • Écritures interdites : s'auto-modifier par dérivation ; stocker une vue dérivée comme source.

② UNIVERS

  • Responsabilités exclusives : détenir le capital et le cadre du monde ; amorcer par copie.
  • Responsabilités interdites : modifier rétroactivement un projet · imposer un lien vivant · décider ·

calculer une lecture de projet.

  • Données possédées exclusivement : briques-modèles, règles éditoriales/visuelles, lignes de

publication, Personnages (références/garde-robe/voix), Séries.

  • Calculs autorisés : aucun (relatif à un projet).
  • Calculs interdits : toute dérivation propre à un projet.
  • Écritures autorisées : être enrichi (promotion d'une brique, par le Pilotage).
  • Écritures interdites : écrire dans un projet ; propager une règle en lien vivant.

③ CONSCIENCE (lecteur dérivé)

  • Responsabilités exclusives : calculer toute la lecture du projet (situation, titre, signaux,

focalisation, hiérarchie des tensions, miroir) ; signaler/décrire.

  • Responsabilités interdites : posséder du durable · écrire dans le Socle · décider (Loi I)

· attribuer le sens (Loi II) · convoquer la matière · créer des faits historiques.

  • Données possédées exclusivement : aucune durable (au plus un cache jetable).
  • Calculs autorisés : situation · titre (4 filtres) · signaux (calme/maturité/tension/priorité) ·

focalisation · stratification des tensions · miroir (fracture/polarité/effondrement, cap déclaré vs agi) ·

vues Historique / inventaire-faits.

  • Calculs interdits : la qualification d'une action (structurant/local pour le routage) ; le

coût de production ; tout calcul destiné à être stocké comme source.

  • Écritures autorisées : aucune (dans le Socle).
  • Écritures interdites : toute écriture durable.

④ ATELIER (production convoquée)

  • Responsabilités exclusives : fabriquer/éditer/comparer la matière sous contrat ; calculer le

coût de production ; déposer des faits-médias (avec RAW).

  • Responsabilités interdites : décider du devenir d'un média (retenu/actif/validé/publié) · rester

au premier plan · calculer la lecture du projet · être le centre.

  • Données possédées exclusivement : aucune durable (matière de travail transitoire avant dépôt).
  • Calculs autorisés : artefacts de production (le média) ; estimation/mesure du coût (domaine

production).

  • Calculs interdits : situation/titre/signaux/tensions/miroir ; statut métier d'un média.
  • Écritures autorisées : déposer dans le Socle des faits-médias + RAW (état initial

candidate uniquement) ; mesure de coût réel (fait).

  • Écritures interdites : modifier le statut de devenir d'un média (variante/actif/retenu/validé/

publié) ; écrire une Décision ; écrire ailleurs que comme fait-média.

⑤ PILOTAGE (orchestrateur des décisions de l'auteur)

  • Responsabilités exclusives : recevoir l'action de l'auteur ; qualifier (structurant/local) et

router ; transformer une action structurante en Décision (+ raison) ; convoquer l'Atelier

; attacher le verdict (statut de devenir) ; écrire décisions/états dans le Socle ; gérer

repos↔travail ; proposer (jamais imposer) ; copier/promouvoir entre Univers et Socle.

  • Responsabilités interdites : originer une décision (Loi I) · attribuer le sens (Loi II) ·

calculer la lecture (situation/titre/focalisation/tensions/miroir) · effacer l'aval en silence.

  • Données possédées exclusivement : aucune durable ; seulement des **pointeurs de session

transitoires (posture, contexte de convocation, projet actif) reconstructibles** (E122).

  • Calculs autorisés : qualification d'une action (structurant/local) selon la règle M15 ;

routage ; mapping du « prochain geste » à partir de la focalisation **calculée par la

Conscience**.

  • Calculs interdits : recomposer situation/titre/focalisation/hiérarchie des tensions/miroir ; calculer

le coût de production.

  • Écritures autorisées : dans le Socle — Décisions+raisons, statuts de devenir (verdicts),

marqueurs de polarité protégée (sur ordre de l'auteur), copies d'amorce ; vers l'Univers — promotions.

  • Écritures interdites : écrire une lecture dérivée comme source ; écrire dans l'Univers un état de

projet.

V3 — Aucun espace ne peut devenir une seconde source de vérité

Statut : 🟢. Preuve : la Conscience ne possède rien et n'écrit rien ; ses sorties sont

recalculables depuis le Socle (INV-9/10) — supprimer son cache et régénérer redonne la même lecture.

Atelier/Pilotage n'ont aucun durable. Seul écrit durable = Socle/Univers.

V4 — Aucun espace ne peut décider à la place de l'auteur

Statut : 🟢. Preuve : la décision est originée par l'auteur ; le Pilotage exécute/propose (Loi

I) ; la Conscience signale (INV-2) sans décider ni interpréter (Loi II) ; l'Atelier **propose de la

matière, le verdict** est une décision (Pilotage exécutant l'auteur).

3 POINTS EXPLICITES (OUI/NON + justification)

P1 — Conscience → Pilotage : le Pilotage ne recalcule JAMAIS la lecture

OUI. Le Pilotage consomme la lecture de la Conscience ; il ne recompose ni situation, ni titre, ni

focalisation, ni hiérarchie des tensions, ni miroir (fiche ⑤ « calculs interdits »). Réserve 🟠 : son

« prochain geste » doit être un mapping de la focalisation calculée par la Conscience, pas une

re-dérivation indépendante → voir ZG-2.

P2 — Atelier → Socle : l'Atelier ne modifie JAMAIS le statut métier d'un média

OUI. L'Atelier crée des faits-médias (état initial candidate + RAW) ; il ne peut pas décider

qu'un média est retenu/actif/validé/publié — ce verdict appartient au Pilotage exécutant l'auteur

(fiche ④ « écritures interdites »). (Renforce le point de vigilance déjà noté en cartographie.)

P3 — Conscience → Mémoire : la Conscience ne crée JAMAIS de faits historiques

OUI. La Conscience relit les Décisions + Raisons du Socle et les réorganise en lecture

(Historique = vue dérivée) ; elle ne crée aucun fait durable. Toute mémoire durable reste **détenue

par le Socle** (fiche ③ « écritures interdites » + « données possédées : aucune durable »).

ZONES GRISES IDENTIFIÉES (recherche adversariale — rien masqué)

🟠 ZG-1 — La règle « structurant » (M15) référencée par deux espaces

  • Constat : la Conscience utilise « structurant vs local » comme filtre de lecture (compression) ;

le Pilotage utilise « structurant » pour qualifier une action (routage → Décision). Deux **usages

distincts** (classer une tension vs qualifier une action), mais le même critère M15. Risque : si

chaque espace réimplémente le critère, ils peuvent diverger.

  • Ce n'est PAS une fuite (objets différents : tension ≠ action ; aucune donnée/calcul partagé). C'est un

risque de divergence de règle.

  • Correction (à graver avant réalisation) : M15 = règle canonique unique (une seule définition de

référence), citée par les deux espaces, jamais redéfinie localement. *(reformulation déjà adoptée :

vocabulaire/critères = source unique.)*

🟠 ZG-2 — Le « prochain geste » proposé par le Pilotage

  • Constat : le Pilotage propose un prochain geste ; ce geste s'appuie sur la focalisation (le

carrefour) calculée par la Conscience. Risque : que le Pilotage re-dérive le carrefour lui-même

(duplication du calcul de focalisation).

  • Ce n'est PAS une fuite tant que le Pilotage consomme la focalisation. C'est un **risque

d'implémentation**.

  • Correction (à graver) : le « prochain geste » est un mapping déterministe de la **focalisation

fournie par la Conscience ; le Pilotage n'a pas le droit** de recalculer le carrefour.

Aucune 🔴 fuite détectée. Les deux 🟠 sont des risques de divergence/duplication à l'implémentation,
neutralisés par deux règles à graver (source unique de M15 ; geste = mapping de la focalisation).

VERDICT GLOBAL

**🟢 Étanchéité conceptuelle VERTE — aucune duplication ni captation de responsabilité au niveau du
modèle. Les 4 vérifications globales sont vertes ; les 3 points explicites sont OUI** ; chaque
calcul appartient à exactement un espace ; tout le durable est dans Socle/Univers ; la Conscience
ne peut pas devenir une 2ᵉ source ; aucun espace ne décide à la place de l'auteur.
2 règles d'étanchéité à GRAVER avant toute réalisation (issues des zones grises, non bloquantes) :
1. M15 = règle canonique unique, citée par Conscience et Pilotage, jamais redéfinie localement
(ZG-1).
2. Le « prochain geste » = mapping de la focalisation calculée par la Conscience ; le Pilotage **ne
recalcule jamais** le carrefour (ZG-2).
Point de vigilance d'implémentation (rappel renforcé, P2) : l'Atelier ne doit jamais inscrire un
statut de devenir — ce verdict est exclusivement au Pilotage.
