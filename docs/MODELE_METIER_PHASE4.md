## 1. LES QUATRE NOTIONS — à ne jamais confondre

> Point de vigilance d'Etoile : **beaucoup de confusions venaient du mélange OBJET / ÉTAT / ACTION /
> DÉCISION.** Cette séparation est le **squelette** de cette phase et reste rigoureuse partout.

| Notion | Définition | Nature | Exemple |
|---|---|---|---|
| **OBJET** | une chose du domaine qui **existe et persiste**, dotée d'une identité | nom | **une Variante** |
| **ÉTAT** | une **condition/qualité** d'un objet à un instant ; n'existe **pas seul** (propriété d'un objet) | adjectif/qualité | **« média actif »** |
| **ACTION** | un **geste** posé par la personne (verbe) : crée un objet, change un état, ou produit un effet | verbe | **« définir comme média actif »** |
| **DÉCISION** | le **choix** — **avec sa raison** — que matérialise une action **structurante** ; la Décision est elle-même un **OBJET de mémoire** | choix + pourquoi | **« j'ai choisi de définir B comme média actif parce que… »** |

### 1.1 Exemple canonique (référence absolue)
> **Une Variante = un OBJET.** **Média actif = un ÉTAT.** **Définir comme média actif = une ACTION.**
> **Le choix de le faire (+ sa raison) = une DÉCISION.**

### 1.2 Les trois niveaux d'une ACTION (conséquence de M13 + M15)
- **✦ Structurante MAJEURE** : change/remplace une direction · valide un état décisif · publie. → **produit une
  Décision** ; **raison OBLIGATOIRE** (M13). *Cas : rejet d'une variante · abandon d'une direction ·
  remplacement d'un élément majeur · validation d'un livrable · publication.*
- **✧ Structurante** : fixe un devenir sans être dans la liste majeure (ex. désigner un média actif,
  conserver une variante). → **produit une Décision** ; **raison PROPOSÉE** (facultative).
- **· Mineure** : réglage **local/technique**. → **ne produit AUCUNE Décision**, **ne pollue pas**
  l'historique décisionnel (M15).

> **Règle d'or de séparation** : l'**ACTION** est le **geste** ; la **DÉCISION** est le **choix (avec
> raison)** que ce geste matérialise. Tout geste n'est pas une décision ; seules les actions
> structurantes le sont.

## 2. PAR OBJET — États · Actions · (structurante ? → Décision/raison)

> Légende colonne « Structurante ? » : **✦** majeure (raison obligatoire) · **✧** structurante (raison
> proposée) · **·** mineure (aucune Décision tracée).

### FAMILLE 0 — UNIVERS

**0. Univers** — *OBJET*
- **États** : `actif` · `archivé`.
- **Actions** :

| Action | Structurante ? | Décision tracée + raison |
|---|---|---|
| Créer l'univers | · | non (acte d'existence) |
| Renommer | · | non |
| Modifier une **règle éditoriale/visuelle** ou une **ligne de publication** | ✦ | **oui — raison obligatoire** (change la direction du monde) |

**29. Décision** — *OBJET (de mémoire)* — *états : `prise` · `incomplète` (sans raison, M17) · `annotée` · `supersédée`*.
| Action | Structurante ? | Décision |
|---|---|---|
| Consigner (action + raison) | — | **c'est l'acte qui CRÉE la Décision** |

## 3. TRANSVERSAL — la distinction ACTION ↔ DÉCISION

- **L'ACTION est le geste ; la DÉCISION est le choix (avec sa raison) que ce geste matérialise.**
- Tout geste **n'est pas** une décision : un **réglage local/technique** (Paramètres, rythme, retouche,
  versionnage) est une **action sans décision** (M15) — il ne pollue pas l'historique décisionnel.
- Une **action structurante** (M15 : change/remplace une direction · fixe un devenir · valide un état ·
  modifie le sens) **produit une Décision** :
  - **raison OBLIGATOIRE** pour les cas majeurs (M13 : rejet de variante · abandon de direction ·
    remplacement d'un élément majeur · validation d'un livrable · publication) ;
  - **raison PROPOSÉE** pour les autres structurantes.
- La **DÉCISION** est un **OBJET de mémoire** : immuable (M14), annotable, supersédable, **jamais
  supprimée** — elle relie l'**ACTION** posée à l'**ÉTAT** atteint sur l'**OBJET** concerné, et explique le
  **pourquoi**.

### 3.1 Le quadruplet, déroulé sur l'exemple canonique
| Notion | Sur l'exemple |
|---|---|
| **OBJET** | la **Variante B** (existe, persiste) |
| **ÉTAT** | « **média actif** » (qualité visée pour B) |
| **ACTION** | « **désigner B comme média actif** » (le geste) |
| **DÉCISION** | « **j'ai choisi B comme média actif parce qu'elle est plus douce et colle à l'émotion visée** » (le choix + raison) → objet de mémoire, alimente l'Historique |

## 4. QUESTIONS DE MODÉLISATION OUVERTES (Phase 4)

| # | Question | Décision (validé 10/06) | Statut |
|---|---|---|---|
| **M16** | Une action peut-elle produire **plusieurs** Décisions ? | **NON — 1 action structurante = 1 Décision.** Les **conséquences automatiques** ne sont **pas** des décisions (ex. valider un livrable = décision ; la version retenue figée = **conséquence**) | ✅ validé 10/06 |
| **M17** | Une action structurante **sans raison** est-elle tracée ? | **OUI — tracée (quoi · quand · sur quoi · par qui)** ; la raison s'ajoute plus tard (M14) ; **ET la Décision sans raison reste IDENTIFIABLE COMME INCOMPLÈTE** (incite à documenter le pourquoi quand il est important) | ✅ validé 10/06 |

> **M1→M17 toutes tranchées.** Frontière action↔décision figée : 1 choix = 1 décision ; conséquences ≠
> décisions ; une décision sans raison est **tracée mais marquée incomplète**.
