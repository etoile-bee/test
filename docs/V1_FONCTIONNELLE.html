V1 FONCTIONNELLE — le plus petit produit utilisable

EN-TÊTE DE GOUVERNANCE (E131)
- Statut : B — Formalisation (traduit le modèle verrouillé en périmètre, sans rien inventer).
- Acquis-source(s) : fondation close (5 espaces + Conscience + Lois I/II + invariants INV-1→15 +
E128–E131) + PARCOURS_UTILISATEUR_CANONIQUE + EXPERIENCE_UTILISATEUR_REELLE + AUDIT_REALISATION
(dont les 10 critères de V1 utilisable).
- Modifie un élément déjà verrouillé : NON.
Objet : définir la plus petite version utilisable permettant un premier usage réel sur mobile.
Principe directeur : testable rapidement > complet. On reste au périmètre fonctionnel (quelles
capacités), pas d'UI, pas de techno. Contrainte ferme : aucun paradigme média-au-centre
(cf. 10 rechutes d'AUDIT_REALISATION) — repos sans média permanent, matière convoquée. Live
intact · zéro dépense.

LES 7 FONCTIONS (× 4 rubriques)

F1 — CRÉER un projet

  • INDISPENSABLE V1 : ouvrir un projet dans un Univers (par défaut accepté) ; copie d'amorce des

valeurs utiles ; poser le déclencheur + une Intention esquissable (message + au moins une

composante) ; identifiant stable ; entrée immédiate en mémoire (brouillon).

  • REPORTABLE V2 : choix multi-Univers / multi-Personnages riches ; capture guidée élaborée des 4

composantes ; gabarits d'intention.

  • DÉPENDANCES : Univers (copie d'amorce) · Socle (écriture du projet) · Pilotage (écrit) · Conscience

(première lecture du repos).

  • IMPACT INVARIANTS : INV-11/M12 (copie, pas de lien vivant) · M18 (identité stable) ·

INV-9/10 (en mémoire, repos lisible) · E130 (vérité projet vs monde).

F2 — REPRENDRE un projet

  • INDISPENSABLE V1 : rouvrir et retomber exactement sur cap + situation + mémoire, **sans aucun

média, instantanément** ; lecture régénérée depuis le Socle.

  • REPORTABLE V2 : tri/recherche avancés de la liste des projets ; vues d'états multiples (récents/

archivés filtrés finement).

  • DÉPENDANCES : Socle (faits) · Conscience (recalcul de situation/titre) · une liste minimale de projets.
  • IMPACT INVARIANTS : INV-9 (survie/reconstruction) · INV-10 (source unique, listes = vues) ·

repos instantané sans média.

F3 — PRODUIRE une image

  • INDISPENSABLE V1 : depuis le repos, convoquer la production sous contrat (coût annoncé) ;

l'Atelier dépose une candidate + RAW ; l'auteur lit et décide le devenir (garder / écarter

/ désigner média actif) + raison (sur le structurant).

  • REPORTABLE V2 : variantes multiples comparées côte à côte ; édition/retouche fine ; planche de

plusieurs candidates ; presets avancés.

  • DÉPENDANCES : Pilotage (commande+contrat, écrit le verdict) · Atelier (produit le fait-média) ·

Conscience (coût estimé, inventaire-faits) · Socle (dépôt + décision).

  • IMPACT INVARIANTS : INV-12 (contrat avant dépense) · E128-3 (Atelier = candidate seulement,

verdict au Pilotage) · INV-5/8 (RAW conservé) · Loi I (l'auteur décide) · **matière =

manifestation**.

F4 — PRODUIRE une vidéo

  • INDISPENSABLE V1 : depuis une image retenue (même projet = source), un script minimal + une

voix, un montage simple ; production sous contrat (coût + gate QC) ; lecture du résultat +

décision de retenue.

  • REPORTABLE V2 : montage multi-plans avancé, réglages fins de rythme/sous-titres/musique, variantes de

script (hooks A/B), multi-parties longues.

  • DÉPENDANCES : F3 (image source) · Pilotage · Atelier · Conscience · Socle.
  • IMPACT INVARIANTS : INV-12 (contrat + QC avant dépense lourde) · un seul projet (image→vidéo

sans changer d'outil) · E128-3 · Loi I.

F5 — GÉRER les décisions et la mémoire

  • INDISPENSABLE V1 : chaque choix structurant persisté comme Décision + raison ; impact aval

présenté (garder / mettre à jour / régénérer) au choix ; historique relisible (actions + raisons) ;

rien d'effacé.

  • REPORTABLE V2 : annotations datées riches, comparaisons de versions élaborées, vues analytiques de la

mémoire, signaux avancés (au-delà du strict nécessaire).

  • DÉPENDANCES : toutes les fonctions (toute décision passe par ici) · Conscience (**impact aval =

dérivation**, historique-vue) · Pilotage (écrit) · Socle.

  • IMPACT INVARIANTS : INV-4 (décision = pourquoi) · M16/M17 (1 action = 1 décision ; sans raison

= incomplète) · AUD-G1 (impact aval calculé par la Conscience, consommé par le Pilotage) ·

INV-6 (réversible, jamais en silence) · INV-5/8 (immuabilité/rien perdu) · Loi II (pas

d'interprétation).

F6 — CONSTITUER un livrable

  • INDISPENSABLE V1 : retenir une version → livrable autoporteur (média final + script + légende

courte + hashtags + paramètres + RAW) ; choix image / vidéo / les deux ; passage à l'état

prêt-à-poster.

  • REPORTABLE V2 : légende longue élaborée + variantes, gabarits de hashtags, exports multiples,

packaging enrichi.

  • DÉPENDANCES : F3/F4 (matière retenue) · Versions · Socle · Pilotage.
  • IMPACT INVARIANTS : INV-9 (paquet complet, autoporteur) · livrable explicite (rien de non

validé) · état prêt-à-poster (vue, pas stock séparé).

F7 — PUBLIER

  • INDISPENSABLE V1 : dernier regard (lecture + faits/invitations du miroir) ; publier = **acte

irréversible, annoncé et confirmé avant ; la version publiée devient figée et reste** en mémoire ;

sort de la file prêt-à-poster.

  • REPORTABLE V2 : auto-diffusion réelle vers une plateforme (hors périmètre acté), planification/

calendrier, métriques de performance.

  • DÉPENDANCES : F6 (livrable prêt) · Pilotage · Socle.
  • IMPACT INVARIANTS : INV-7 (seul acte irréversible) · INV-12 (annoncé avant) · Loi I/II (le

verdict final + le jugement de cohérence = l'auteur).

SYNTHÈSE DU PÉRIMÈTRE MINIMAL (V1 vs V2)

ENTRE EN V1 (le strict utilisable) :

  • créer (Univers par défaut, intention esquissable, identité stable, en mémoire) ;
  • reprendre (repos instantané, sans média) ;
  • produire 1 image (contrat → candidate+RAW → décision+raison) ;
  • produire 1 vidéo simple (image retenue → script+voix+montage simple, contrat+QC) ;
  • décisions+mémoire (raison sur le structurant, impact aval au choix, historique relisible) ;
  • livrable autoporteur (image/vidéo/les deux, prêt-à-poster) ;
  • publier (irréversible, annoncé, confirmé).

REPORTÉ EN V2 (sans casser l'usage) :

  • comparaison de variantes, édition fine d'image, planche multi-candidates ;
  • montage avancé (multi-plans, rythme/sous-titres/musique fins), hooks A/B, vidéos longues multi-parties ;
  • légende longue élaborée + gabarits, exports multiples ;
  • tri/recherche/vues d'états avancés ;
  • auto-diffusion réelle, planification, métriques ;
  • signaux/lectures avancés au-delà du nécessaire.

ARBITRAGES DE RÉDUCTION DE PÉRIMÈTRE (ce qu'on coupe pour aller vite — sans risque modèle)

1. Une seule candidate à la fois (pas de planche/comparaison) → coupe une commodité de lecture ; la

décision reste explicite (E128-3). Sans risque (INV intacts).

2. Montage simple (pas de multi-plans/rythme fin) → coupe de la richesse de production ; un seul

projet image→vidéo préservé. Sans risque.

3. Légende longue + gabarits reportés → le livrable reste autoporteur avec l'essentiel (courte +

hashtags). Sans risque (INV-9 tenu).

4. Pas d'auto-diffusion → conforme au périmètre déjà acté ; « publié » = statut + dossier prêt. **Sans

risque** (INV-7/12).

5. Vues/tri avancés reportés → la reprise et l'historique minimaux suffisent (INV-9/10). **Sans

risque**.

Aucune coupe ne touche un non-négociable : repos sans média, Loi I/II, source unique, étanchéité,
contrat, publier irréversible, impact aval = Conscience, Atelier = faits-médias — tous préservés.
(Si une coupe les menaçait, elle serait signalée et écartée — ce n'est le cas d'aucune.)

NOTE HONNÊTE — GÉNÉRATION RÉELLE PAYANTE (image/vidéo)

  • V1 doit pouvoir être testée avec de la vraie matière, MAIS **toute dépense reste sous

confirmation explicite (INV-12, règle d'or des coûts) : rien ne se génère sans contrat accepté**.

  • Zéro dépense sans GO d'Etoile : tant qu'Etoile ne l'autorise pas, la production réelle reste gatée

(la V1 peut être éprouvée sans engager de coût). La bascule « génération réelle ON » est une **décision

séparée d'Etoile**, jamais prise par défaut.
