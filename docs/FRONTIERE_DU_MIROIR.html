FRONTIÈRE DU MIROIR — verrouillée sur A (factuel/structurel)

Statut : ANALYSE — frontière gravée. Document court et tranchant. **Aucune nouvelle règle métier,
aucun nouvel objet, aucune implémentation. Live intact · zéro dépense. Ancré sur la Loi II** (« la
conscience décrit les régularités, n'attribue jamais leur signification ») + CONSCIENCE_DU_PROJET.
Tranché : le MIROIR = A — un miroir strictement FACTUEL/STRUCTUREL qui détecte uniquement des
écarts observables dans les FAITS du Socle et reflète les jugements déjà enregistrés par
l'auteur. B est INTERDIT : un évaluateur qui déciderait lui-même si une pièce « sert » l'intention/
l'émotion/le message violerait la Loi II.

1. CE QU'IL PEUT AFFIRMER

Faits observables (mesurables/structurels) :

  • durée > borne du format (objectif) ;
  • pièce modifiée APRÈS la dernière version de l'intention (antériorité = fait) ;
  • pièce manquante alors que l'objectif l'exige ;
  • divergence COMPTÉE entre cap déclaré et cap agi (un décompte, pas un sens) ;
  • absence de version retenue ;
  • nombre de plans ≠ règle de durée (conformité numérique).

Reflet des enregistrements de l'auteur :

  • « tu as enregistré un écart assumé ici » ;
  • « tu as revendiqué cette polarité » ;
  • « tes N dernières décisions ont retenu l'option X » (régularité comptée).

2. CE QU'IL NE PEUT JAMAIS AFFIRMER (domaine de l'auteur)

  • « cette image sert / ne sert pas l'intention » ;
  • « le ton du script correspond à l'émotion » ;
  • « c'est cohérent / incohérent » au sens du message ;
  • « c'est bon / fort / faible » ;
  • « ton vrai sujet est X ».
Tous ces énoncés attribuent un sens → interdits (Loi II).

3. CE QUI EST UN FAIT (domaine du miroir)

Tout ce qui est mesurable ou structurellement vérifiable depuis le Socle :

  • durées, comptes, nombres ;
  • présence / absence d'une pièce ;
  • antériorité (« modifié-après ») ;
  • divergences comptées ;
  • existence d'un jugement enregistré (écart assumé, polarité revendiquée) ;
  • conformité à une règle / un format.

4. CE QUI EST UN JUGEMENT D'AUTEUR (interdit au miroir)

  • l'adéquation sémantique (« sert l'émotion / le message ») ;
  • le SENS d'une régularité (pourquoi ce motif) ;
  • la qualité esthétique / émotionnelle ;
  • fracture vs polarité féconde (distinguer un blocage subi d'une tension voulue est un jugement de

sens → à l'auteur).

5. FORMES DE SIGNALEMENT COMPATIBLES LOI II

  • (a) Observation factuelle — « X est vrai dans les faits » (durée > format ; pièce manquante).
  • (b) Reflet d'un enregistrement de l'auteur — « tu as assumé un écart ici » ; « tu as revendiqué

cette polarité » ; « tes N dernières décisions ont retenu X ».

  • (c) Fait + INVITATION À JUGER — « cette pièce a été fixée avant ton dernier recentrage — veux-tu la

revérifier ? ». L'invitation renvoie le jugement à l'auteur, elle ne conclut pas.

Motif compatible = « observation factuelle + invitation », jamais « conclusion sémantique ».
Le miroir montre un fait et pose une question ; il ne tranche pas le sens.

6. CONSÉQUENCE HONNÊTE — un miroir MODESTE

Le miroir ne peut pas, seul, dire « cette vidéo ne porte pas l'émotion ». La **cohérence

SÉMANTIQUE reste toujours le jugement de l'auteur. Le rôle du miroir est de le faire

REMARQUER (un fait + une question), pas de conclure**.

Modeste ≠ inutile : faire remarquer le bon fait au bon moment déclenche le jugement de l'auteur —
sans jamais le remplacer.

7. CAS DE LA POLARITÉ PROTÉGÉE — limite stricte

  • Le miroir ne peut signaler un « effondrement » que s'il est détectable STRUCTURELLEMENT : la

condition des deux pôles devient factuellement non remplie (ex. un pôle reposait sur une pièce

désormais absente / supprimée, ou sur un réglage factuellement à zéro, ou une décision a

explicitement retiré ce pôle).

  • Si constater l'effondrement exige du sens (« est-ce encore doux ? ») → INTERDIT : c'est un

jugement d'auteur. Le miroir peut alors au plus refléter un fait adjacent (« le pôle “douceur”

reposait sur la pièce P, modifiée après ta revendication — à revérifier ? ») — jamais conclure que

la douceur a disparu.
